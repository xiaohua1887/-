# 界面感知问卷：两个试测版本

| 页面 | 每份问卷 | 套数 |
| --- | --- | --- |
| [六维版](https://xiaohua1887.github.io/-/) | 6维 × 每维16组，共96题 | 保留原50套配对 |
| [三维版](https://xiaohua1887.github.io/-/three35.html) | 3维 × 每维35组，共105题 | 3套试测，不保证全覆盖 |

两版统一使用维度说明、作答教学、3道操作练习、2道理解确认、三类选项、图片尺寸及双图大图对比。练习使用独立示意图，不计入正式排序或正式用时。

## 维度

- 一致性：图标、色彩、字体和排版是否协调统一，整体风格是否连贯。
- 活力感：是否显得活跃、鲜活、轻快，具有朝气、能量、动感和节奏感。
- 趣味感：是否显得有意思、好玩、俏皮，带有幽默、巧思或值得玩味的细节。
- 科技感：是否呈现技术化、数字化的视觉风格，让人联想到智能系统或未来技术。
- 新潮感：是否显得现代、时髦、有时代感，符合当下流行的设计风格。
- 高级感：是否显得精致、细腻、考究和优雅，整体具有经过精心设计的品质感。

每个维度开始前展示说明。评价的是视觉感知，而非喜好或真实功能。

## 作答及导出

选项随维度变化，例如“左图更一致／两图差不多／右图更一致”。response_score_left依次为+1、0、-1；另记录相对原始左图及编号较小界面的方向换算。类别编码不等于等距感知分数。

可随时下载已答CSV，完成后也可下载JSON。CSV包含逐题答案、界面编号、完成状态、完成时间和逐题用时；JSON另含独立练习记录、教学记录和暂停事件。结果只保存在当前浏览器，不自动上传。

正式总用时从开始正式题至完成，包含加载、暂停、休息及离开页面；有效作答时间只累计图片加载完成、页面可见且未暂停的正式答题时间。教学练习不计入两项正式用时。两版导出文件名和study_version不同，便于区分。

六维版每16题可休息并介绍下一维度；三维版每维第18题有额外休息机会。两版均可主动暂停。数字键1—3选择，Enter确认；支持鼠标和触屏。

## 指定问卷

链接可附加 ?form=01&orientation=A&country=CN。六维版支持01—50，三维版支持01—03。A/B互换配对左右位置，维度顺序也可能不同；实际顺序与位置完整记录。随机分配不保证名额均衡。

## 材料及版本

六维版保留原50套的全部4800个配对，仅将intelligence维度代码改为technology，并更新维度名称及定义；206张正式界面图片未更改。

当前版本为ui-pilot-6x16-three-category-2.0及ui-pilot-3x35-three-category-2.0。新版使用独立进度存储，不将旧五级答案作为新版答案恢复；浏览器中的旧存储未删除。

index.html加载六维版的data.js、core.js、app.js和styles.css；three35.html内嵌三维版代码及数据。两者共用images目录。

在此目录运行 python -m http.server 8765 --bind 127.0.0.1，再打开 http://127.0.0.1:8765/ 即可本地测试。
